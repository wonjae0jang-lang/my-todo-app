# Little Snake Club 🐍

브라우저에서 바로 즐기는 스네이크 게임입니다. 설치나 빌드 없이 HTML, CSS, JavaScript만으로 만들었습니다.

## 실행 방법

1. 저장소를 내려받습니다.
   ```
   git clone https://github.com/wonjae0jang-lang/my-todo-app.git
   ```
2. `index.html` 파일을 브라우저로 엽니다.

## 조작 방법

| 입력 | 동작 |
| --- | --- |
| `↑` `↓` `←` `→` | 뱀 이동 |
| **게임 시작** / **다시 시작** 버튼 | 새 게임 시작 |
| **일시정지** / **재개** 버튼 | 게임 멈춤 / 이어하기 |

## 게임 규칙

- 20 × 20 칸 보드에서 빨간 사과를 먹으면 뱀이 한 칸 길어지고 **10점**을 얻습니다.
- 벽이나 자기 몸에 부딪히면 게임이 끝납니다.
- **50점**마다 레벨이 오르고, 레벨이 오를 때마다 뱀이 조금씩 빨라집니다.
- 최고 점수는 브라우저에 저장되어 다음에 접속해도 유지됩니다.

## 난이도

게임을 시작하기 전에 난이도를 고를 수 있습니다. 숫자는 뱀이 한 칸 움직이는 간격입니다.

| 난이도 | 이동 간격 |
| --- | --- |
| 쉬움 | 200ms |
| 보통 (기본값) | 150ms |
| 어려움 | 100ms |
| 매우 어려움 | 50ms |

레벨이 하나 오를 때마다 이동 간격이 10ms씩 줄어들며, 가장 빠를 때는 30ms입니다.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `index.html` | 화면 구조 (점수판, 게임 보드, 난이도 선택, 버튼) |
| `style.css` | 화면 디자인 |
| `main.js` | 게임 로직 (이동, 충돌 판정, 점수와 레벨, 최고 점수 저장) |
